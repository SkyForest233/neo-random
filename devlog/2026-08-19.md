## 🐛 已知问题 / 经验教训

1. **带边框图层禁止透明度/位移动画**——半透明或亚像素阶段边框抗锯齿不全，结束帧"由细变粗"。方案：边框外壳静止，动画只发生在被裁剪的内容层（详见 docs/DESIGN.md 动画红线）
2. **`fillMaxSize/matchParentSize/纵向 weight` 在无限高度滚动容器中不可靠**——组件定高一律内容驱动 + 显式 padding 预留阴影
3. **GitHub App 令牌无 workflows 权限**——workflow 文件只能由用户网页创建，Agent 只能读
4. **AnimatedContent 双面板互换在滚动容器中易跳变**——优先单面板 + AnimatedVisibility 收起尾部（chrisbanes compose-animations skill 决策表）
5. Actions 日志 Blob 存储被沙箱网络拦截——通过 gradlew 把编译错误转 `::error::` annotations 经 API 读取
