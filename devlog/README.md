# 开发日志（devlog）

## 规范

- 每个开发日/会话一个文件：`YYYY-MM-DD.md`（同一天多次会话则追加）
- **每次开发会话结束前必须更新当日日志**，包含三节：
  1. ✅ 本日完成事项（列表，关联模块/文件）
  2. 📋 待办事项（TODO，按优先级）
  3. 🐛 已知问题 / 经验教训（踩坑记录，防止回归）
- 日志由开发助手（Claude / 其他 Agent / 开发者本人）在提交代码前写入，与代码同仓库提交
- 文件按日期倒序无要求，自然追加即可
