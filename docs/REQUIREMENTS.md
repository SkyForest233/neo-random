# 开发需求（REQUIREMENTS）

> 来源：网页版 `neo random.html`（功能基准）+ App 端增强需求（用户确认）

## 1. 产品定位

Neo-Brutalism 风格随机数工具：硬币 / 数字生成器 / 加权转盘 三模块 + 命运小票记录。

## 2. 功能需求（与网页版 1:1）

| 模块 | 需求 |
|---|---|
| 🪙 Coin | 自定义正/反面文字；点击硬币或按钮翻转；1% 概率 EDGE 竖立（`[SYSTEM ERROR: EDGE LANDING]` + 红色警报 3s + 警笛 + 长震动）；正常落地 = ding + 三连震 + 纸屑 + 记录 |
| 🔢 Number | MIN/MAX/COUNT；绝对唯一（区间不足时红字报错）；结果逐个弹出（100ms/个 + tick 声震）；完成 ding + 纸屑 + 记录 `[min-max] → n1, n2…`；远程源单次上限 200 |
| 🎡 Wheel | 每行一个选项，支持 `选项 x数字` / `选项 *数字` 权重语法；抽中剔除开关；中心 SPIN；指针跨扇区 tick；结果印章（-6° 回弹，4s）；空列表显示 EMPTY |
| 🧾 小票 | 最多 30 条记录（新的在前）；翻面统计：COIN HEADS/TAILS/EDGE 比例条 + 转盘 TOP3（全部历史口径）；撕毁清空动画（下坠旋转淡出）；系统分享（固定文案格式） |
| 🎨 主题 | 3 套色系（赛博酸性/复古印刷/柔和薄荷）× 深浅模式，实时切换 + 持久化 |
| 🔮 随机源 | RANDOM.ORG / CF DRAND / LOCAL / HYBRID MIX 四态循环；4s 超时或配额限制自动降级本地 + Toast 提示 |
| 🔊 感官 | WebAudio 五音效合成移植；全局静音开关（同时关震动）；震动分级（tick 轻震/ding 三连/警报长震）；五彩纸屑 |
| 💾 持久化 | 所有输入 + 历史 + 设置；**键名与 JSON 结构同网页版 localStorage 完全一致** |
| 📱 手势 | 左右滑动切 Tab（阈值 60dp 且水平位移 > 1.5×垂直）；外接键盘空格触发当前模块（输入框聚焦时除外） |

## 3. App 端增强需求（网页版没有）

| 功能 | 说明 |
|---|---|
| 小票折叠 | 单面板手风琴：折叠只显示最近 6 条；📊 统计两态均可用（全量口径） |
| HYBRID MIX | 三源并行逐位求和取模混合，任一远程源失败自动降级 |
| 崩溃报告页 | 未捕获异常写文件，下次启动显示纯 View 报告页（可复制/可继续进入） |
| 分享 | ACTION_SEND 系统分享面板 |
| 无障碍 | 核心交互元素 contentDescription |

## 4. 非功能需求

- minSdk 26（Android 8.0）；target/compileSdk 36
- 冷启动 < 1s；空闲不产生持续 CPU 占用（动画引擎空闲零写入）
- 离线可用（降级本地随机）
- 不收集任何用户数据；allowBackup=false
